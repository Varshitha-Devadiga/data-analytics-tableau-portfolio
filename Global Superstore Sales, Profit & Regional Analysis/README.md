# Global Superstore Sales, Profit & Regional Analysis

## Overview

This project contains Tableau visualizations created using Global Superstore data to analyze sales, profit, category, sub-category, and regional performance.

## Visualizations

### 1. Profit by Category & Sub-Category
Analyzed total profit across different categories and sub-categories.

### 2. High-Profit Sub-Categories (> 50K)
Identified sub-categories with profit greater than 50,000 using a bar chart with different colors.

### 3. Regional Sales by Year
Analyzed region-wise total sales across different years using a side-by-side bar chart.

### 4. Maximum Regional Sales by Year
Analyzed the maximum sales achieved by each region across different years.

### 5. Sales by Category & Sub-Category – Bubble Chart
Visualized sales across categories and sub-categories using a bubble chart.

## Tools Used

- Tableau

- Data Visualization
