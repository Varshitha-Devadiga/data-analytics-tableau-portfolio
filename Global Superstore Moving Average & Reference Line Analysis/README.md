# Global Superstore Moving Average & Reference Line Analysis

## Overview

This Tableau project analyzes Global Superstore data using moving averages and reference line techniques to identify sales and profit trends.

## Analysis Performed

### Reference Line Analysis
- Average sales by category
- Average sales by category and sub-category
- Reference lines per table and per pane
- Top 3 countries by total profit in 2014
- Average profit analysis
- Top 3 sub-categories by average shipping cost in the United States

### Moving Average Analysis
- Monthly profit trend with a 3-month moving average
- Furniture monthly sales with a 5-month moving average using dual axis
- Monthly sales compared with overall average sales
- Regional profit and loss analysis using a reference line
- Sub-category sales with a 7-month moving average
- Reference lines for overall average sales

## Tools Used

- Tableau
- Excel
- Data Visualization
- Moving Average
- Reference Lines
- Dual Axis
- Table Calculations
