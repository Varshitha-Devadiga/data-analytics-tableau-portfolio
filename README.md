## 📊 Tableau Projects

### Global Superstore Sales & Profit Analysis

An interactive Tableau analysis of Global Superstore data focusing on sales, profit, shipping cost, reference lines and moving averages.

#### Analysis Performed

- Average Sales by Category using Reference Lines
- Average Sales by Category and Sub-Category
- Reference Lines per Table and per Pane
- Top 3 Countries by Total Profit in 2014
- Average Profit Reference Line
- Top 3 Sub-Categories by Average Shipping Cost in the United States
- Monthly Profit Trend with 3-Month Moving Average
- Furniture Monthly Sales with 5-Month Moving Average and Dual Axis
- Monthly Sales compared with Overall Average Sales
- Regional Profit and Loss Analysis using Reference Lines
- Sub-Category Sales with 7-Month Moving Average
- Reference Lines per Table and per Pane
